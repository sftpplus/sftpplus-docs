SFTPPlus AS2 Drummond certification
###################################

..  contents:: :local:


Introduction
============

SFTPPlus is a `Drummond-certified AS2 product
<https://www.sftpplus.com/articles/2025/as2-certification-path>`_, meaning its AS2 implementation
has passed independent interoperability testing and meets recognized technical
standards for secure B2B data exchange. This certification validates that
SFTPPlus works reliably with other certified AS2 file transfer solutions in real-world
B2B scenarios.


What Drummond certification signifies
=====================================

For SFTPPlus, this means the AS2 implementation was assessed against defined
technical criteria and verified in controlled interoperability scenarios,
including protocol behavior, secure message processing, and AS2 conformance.

For AS2 deployments, this certification independently confirms that the
implementation was tested beyond a single-vendor environment.
For organizations exchanging business-critical data with many partners, this
helps reduce protocol-compatibility risks during onboarding and operation.

In practice, this can help teams:

* speed up partner onboarding by reducing protocol-level uncertainty
* lower integration friction in multi-partner ecosystems
* support compliance and audit discussions by providing an independent
  certification reference


AS2 support in SFTPPlus
=======================

SFTPPlus's AS2 implementation is based on:

* `RFC 4130 <https://www.rfc-editor.org/rfc/rfc4130>`_ for AS2 message exchange.
* `RFC 5652 <https://www.rfc-editor.org/rfc/rfc5652>`_ for CMS signing and
  encryption.
* `RFC 8098 <https://www.rfc-editor.org/rfc/rfc8098>`_ for MDN processing.

For the supported cryptographic standards, see
:doc:`/standards/cryptography`.

If you encounter compatibility issues with a specific AS2 partner or
implementation,
get in touch with our support team.
We will work to extend AS2 support to cover non-standard AS2 implementations
in order to offer maximum interoperability.
